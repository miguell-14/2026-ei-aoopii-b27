# Data
The dataset is not stored locally in this repository due to its size.
All experiments were conducted using the **DeepFashion-MultiModal** dataset, uploaded as a private dataset on Kaggle.

Original dataset available at:
https://github.com/yumingj/DeepFashion-MultiModal

To reproduce the results:
- Open the notebooks in Kaggle
- Attach the DeepFashion-MultiModal dataset
- Run the notebook cells in order (01 → 06)

No local data is required.
